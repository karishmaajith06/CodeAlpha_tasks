🧮 Basic Calculator
📌 Project Overview

Basic Calculator is a responsive and interactive calculator website developed as part of the CodeAlpha Frontend Development Internship – Task 2.

The project provides a simple and user-friendly interface to perform basic arithmetic operations such as addition, subtraction, multiplication, and division. Users can enter numbers, select operators, view calculation results, and clear the display easily.

🎯 Objectives
Design an attractive and responsive calculator interface.
Create an organized layout using HTML and CSS.
Implement arithmetic operations using JavaScript.
Handle user input and display calculation results.
Provide smooth transitions and hover animations.
Ensure compatibility across different screen sizes.k
✨ Features
Responsive Design: Works on desktops, tablets, and mobile devices.
Arithmetic Operations: Supports addition, subtraction, multiplication, and division.
Interactive Buttons: Allows users to enter numbers and operators easily.
Clear Function: Clears the calculator display.
Delete Function: Removes the last entered character.
Real-Time Display: Displays user input and calculation results.
Keyboard Support: Allows users to perform calculations using keyboard keys.
Error Handling: Handles invalid expressions and division by zero.
Hover Effects: Adds interactive visual effects to calculator buttons.
Smooth Transitions: Provides a better browsing experience.
🛠️ Technologies Used
HTML5 – For website structure.
CSS3 – For styling, layouts, animations, and responsive design.
JavaScript – For calculations, button interactions, and keyboard functionality.

🚀 How to Run the Project
Clone or download this repository.
Open the project folder in Visual Studio Code.
Make sure all HTML, CSS, and JavaScript files are available in the project folder.
Open "index.html" in your browser.
Explore the calculator and try its interactive features.

You can also use the Live Server extension in Visual Studio Code to run the project.
